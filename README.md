## 📂 Projects

### 🛡️ Security tooling

| Project | What it is | Stack |
|---|---|---|
| [**ScamLens ID**](https://github.com/patrickivanuellf/scamlens-id) | Detects Indonesian phishing and scam messages and links (fake courier APKs, prize scams, phishing URLs) with an explainable risk score | `Python` |
| [**credential-sentinel**](https://github.com/patrickivanuellf/credential-sentinel) | Scans local or GitHub repos for leaked credentials (API keys, tokens, private keys) and redacts every match before it's shown | `TypeScript` `Bash` |
| [**VoidSpider**](https://github.com/patrickivanuellf/VoidSpider/tree/main) | Passive security audit scanner for websites and local files, with a realtime graph dashboard, secret and malware detection (rules + ML), and optional OWASP ZAP integration | `Python` |
| **SSH Log Analyzer** | Parses auth logs to detect SSH brute-force patterns | `TypeScript` |
| **Linux Hardening Audit** | CLI that audits a Linux server against hardening best practices | `Python` |
| **Website Security Checker** | CLI that checks a site's headers, TLS config and common misconfigurations | `Python` |
